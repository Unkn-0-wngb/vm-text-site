How it works

From voice to text in three steps

Add VM-Text

Add it to your Discord account to use it in any chat, or to a server so it works for everyone there.

Pick a voice message

Right-click it (or long-press on mobile), choose Apps, then Transcribe. On a server with auto mode, it just happens.

Read it

The transcript appears in seconds, with who said it, who asked, the language and how long it took.

Privacy

Built to keep as little as possible

Your audio is transcribed on our own server using an open-source model. It is never sent to an outside AI service, and it is deleted as soon as the transcript exists.

FAQ

Questions, answered

Is VM-Text free?

Yes. It's a free personal project with no ads and no paid tiers.

Does it save my voice messages?

No. The audio is held in memory while it's transcribed and then thrown away. Only your language and output settings are stored.

Why does it need the Message Content permission?

So it can see that a message in a server is a voice message and fetch its audio. It doesn't read or store ordinary text messages.

What's the difference between adding it to my account and to a server?

On your account, you can use the Transcribe commands in any DM, group chat or server, but only when you ask. On a server, the bot can also reply to every voice message automatically.

How do I turn off automatic replies?

Someone with the Manage Server permission can run /config and switch automatic transcription off.

The transcript is wrong. Why?

Background noise, strong accents, names and overlapping speech can trip it up. Setting the correct language in /config usually helps.
